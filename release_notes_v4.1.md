## Yleaf v4.1.0

- **Dashboard now integrates with [UYSD](https://ysnp.erasmusmc.nl/) (Y-SNP Database).**  Each yfull prediction shows an embedded haplogroup-frequency world map; one click opens the full UYSD page in the system browser.  A new *Submit to UYSD* panel lets you upload a result directly from the dashboard — with per-sample country/region autocomplete (driven by UYSD's accepted list), CSV import/export, multi-sample bulk-apply for shared metadata, and login + result polling baked in.  Map URLs are cached locally so frequency maps appear instantly on revisit.
- **VCF input now produces real predictions on whole-genome inputs.**  `_infer_from_reference()` is wired back into the VCF flow (issue #39 regression), so the ~99% of YFull markers absent from a typical VCF are inferred from `chrY.fa` instead of being dropped.  Plain `.vcf` files (no bgzip / no index) are now bgzipped on intake and processed through the same code path as `.vcf.gz`, fixing the silent *"No haplogroups found"* failure reported in issue #54.  Duplicate marker BED entries (one per discriminated haplogroup in the shipped data files) are deduplicated by position so they no longer inflate downstream counts by 2–6×.
- **`--ref-fasta` is now validated against `--reference_genome`.**  Passing an hg38 FASTA with `-rg t2t` (or any other mismatch) raises a clear error citing observed-vs-expected chrY length, instead of silently producing empty output.
- **Ancient-DNA position files regenerated** as main file minus `C→T` / `G→A` rows (the two post-mortem deamination patterns).  Marker counts roughly double: hg19 yfull 82 k → 145 k, hg38 yfull 82 k → 147 k, t2t yfull 81 k → 109 k.  FTDNA aDNA files are now shipped too (previously referenced in code but missing on disk — `-tree ftdna -aDNA` no longer crashes).
- **T2T marker names restored.**  `yleaf/data/t2t/new_positions.txt` was shipping with the SNP-name column blank, causing empty `Hg_marker` entries in `.hg`, `.out`, `.fmf`, `.mix`, and the JSON sidecar for any T2T run.  The 168,771-row file now has every marker name populated, with 21 out-of-range positions and 7,977 duplicate positions removed in the regeneration.
- **Reference-inference now works on T2T too.**  `yleaf/data/t2t/chrY.fa` shipped as a 0-byte placeholder and silently disabled reference inference for T2T VCF runs — now populated from `chm13v2.0.fa` (~63 MB).
- **Python 3.7 compatibility restored** for the bundled PyInstaller sidecar: replaced all `Path.unlink(missing_ok=True)` calls (added in 3.8) with a small helper.
